## Python - Setup

Python is usally shipped with Linux but you can check if you have it from the command line.   
To check you can type the following into the command line...   
  

    
    
    $ python3
    

If there is an error than you'll have to install it. If you aren't so familiar with the terminal thats okay you don't have to be an expert just know basics. You can quickly read up on some basic terminal commands [here](https://defunsm.github.io/posts-output/terminalshell/).   
  


If you don't yet have a prefered text editor and want to get to writing python code right away I suggest [pycharm](http://www.jetbrains.com/pycharm/). It is a really nice IDE specifically geared for python. Overtime though I suggest trying out other text editors such as Vim, Emacs, Sublime, or Atom.   
  
However for the purposes of this pretty much any text editor will work as long as it can run python code.
