## SMChat

### What is SMChat?

SMChat is a clojure coded graphical user interface \(GUI\) using the SeeSaw Library.   
  
![SeeSaw Clojure nrepl](https://defunsm.github.io/img/smchat1.jpeg)   
  


### What features does SMChat have?

SMChat is still largely unfinished and being worked on.   
  


  * Clearing Messages
  * Changing Prompt
  * Font Color
  * Theme
  * Login Feature  
  
![clojure](https://defunsm.github.io/img/smchat2.jpeg)  
  


### What lies in the future for SMChat?

Tons of updates and features.   
  

  * Implementing chatbots.
  * A clear registration.
  * Access to SMChat through a web browser.
  * Creating a SMChat version for Linux.
  * A ton more.



  
  


### Where can I go and download SMChat?

You can find SMChat for Windows [here](https://github.com/defunSM/smchat/releases).
