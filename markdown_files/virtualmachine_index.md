## Virtual Machine

## Run an operating system on a Virtual Machine

  
  


### FAQ:

#### What is a virtual machine?

A virtual machine is an application that emulates a computer.   
  


#### Can the virtual machine effect my host machine?

No and Yes. Unless you are sharing a network or have shared folders you should have no problem.   
  


#### How do I run a virtual machine?

Downloading [virtual box](https://www.virtualbox.org/) or [vmware](http://www.vmware.com/).   
  


#### Which is better Vmware or Virtual Box?

Personally I use Virtual Box and this guide will show you how to use virtual box.   
  


## Requirements for Virtual Machine

1 ISO file 1 Computer / Laptop [Virtual Box](https://www.virtualbox.org/)   
  


## General Steps

  
  
Download ISO file \([Ubuntu](http://www.ubuntu.com/desktop)\) Download [Virtual Box](https://www.virtualbox.org/) Create a virtual machine Set up Virtual Box Run the ISO file   
  


## Specific Steps

  
  


#### Step 1: Download ISO File

  
  
_[You can download Ubuntu from their website.](http://www.ubuntu.com/desktop)_   
  


#### Step 2: Download Virtual Box

  
  
_[You can download Virtual Box from their website.](https://www.virtualbox.org/)_   
  


#### Step 3: Create a virtual machine

  
  
To do this open up Virtual Box. _Click on the new button._   
  
![virtual machine](https://defunsm.github.io/img/vm1.png)   
  
_Type in the name of the operating system in this case ubuntu and it should automatically fill in the other fields._ ![virtual box](https://defunsm.github.io/img/vm2.png) **Note:** If it doesnt automatically detect fill in the fields according to what operating system you want to run.   
  
_Next is to select the RAM._ Usually it is fine to just use the recommended amount unless you plan on running an extensive program. In which case you may wish to increase the RAM.   
  
![RAM Virtual Box](https://defunsm.github.io/img/vm3.png)   
  
_It should by default be on virtual hard disk._ Unless you want to specifically store it on another physical hard disk pick virtual.   
  
![virtual memory on disk](https://defunsm.github.io/img/vm4.png)   
  
_Go with the default VDI which is the file type that the virtual disk image will be saved as._   
  
![VDI disk image](https://defunsm.github.io/img/vm5.png)   
  
_Select the dynamically allocated otherwise it'll store it on your physical drive._   
  
![dynamically allocated virtual box](https://defunsm.github.io/img/vm6.png)   
  
_Select the total amount of space the virtual disk can take up on your computer_ Normally this should just be set to the default unless you will be downloading a lot of things.   
  
![Amount of space the virtual disk will take up](https://defunsm.github.io/img/vm7.png)   
  
_Now you should have the virtual machine set up._ Now to select the ISO image you want to run on the virtual machine click settings.   
  
![Setting the ISO image](https://defunsm.github.io/img/vm8.png)   
  
_To select the ISO image you want to run do the following ... Go to Storage->Empty->CD Icon \(Boxed in Green\)_   
  
![ISO IMAGE](https://defunsm.github.io/img/vm9.png)   
  
_Select the ISO image you want to run. In this case it is the Ubuntu ISO file._   
  
![Select ISO image](https://defunsm.github.io/img/vm10.png)   
  
_Now you are selecting the ISO image and can click ok to exit._   
  
![Done with set up for virtual machine](https://defunsm.github.io/img/vm11.png)   
  
_You have everything set up and now can click start and can now run the operating system._   
  
![Running virtual machine](https://defunsm.github.io/img/vm12.png)
